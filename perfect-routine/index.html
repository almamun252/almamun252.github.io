Made for your workflow

A calmer way to get things done.

দৈনন্দিন কাজ থেকে focused session—প্রয়োজনীয় টুলগুলো এক জায়গায় রাখার জন্য তৈরি।

✓

Task management

Learning, Research ও Work অনুযায়ী task সাজাও। Priority, description এবং deadline যোগ করো; দরকারি কাজ Temp list-এ দ্রুত লিখে রাখো।

◷

Focus timer

Pomodoro বা Stopwatch mode বেছে নিয়ে task-এর সঙ্গে focus session যুক্ত করো এবং সময়ের হিসাব রাখো।

⌁

Deadline reminders

গুরুত্বপূর্ণ deadline-এর reminder schedule করো এবং notification settings নিজের প্রয়োজন অনুযায়ী সামলাও।

▤

Time tracking

কোনো task-এ কত সময় দিয়েছ, saved focus session থেকে তা পর্যালোচনা করো।

▦

Home-screen widget

Android home screen থেকেই task information দেখো এবং widget action ব্যবহার করো।

▧

Notes & categories

Task-এর note-এ image attach করো, category তৈরি করো এবং কাজের তথ্য নিজের মতো গুছিয়ে রাখো।

Simple by design

Your work stays yours.

Perfect Routine-এর task, category, focus-session record এবং attached images অ্যাপের local storage-এ রাখা হয়। এই project-এর Android manifest-এ INTERNET permission ঘোষণা করা নেই।

Designed for Android

Native Android experience built with Kotlin and Jetpack Compose.

  • Minimum Android version: 8.0 (API 26)
  • Local database powered by Room
  • Notifications and focus-session service

Before installing

Reminder delivery Android version, notification permission, exact-alarm access এবং device battery settings-এর ওপর নির্ভর করতে পারে।

শুধু official GitHub release থেকে APK ডাউনলোড করো। Install করার আগে release notes ও app permissions দেখে নাও।
